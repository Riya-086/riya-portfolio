# Riya Rakholiya: Software Engineer Portfolio

Personal portfolio site with engineering case studies, professional experience, projects and skills.

**Live site:** https://riya-086.github.io/riya-portfolio/

Built as a static site (HTML, CSS and a little JavaScript, no build step) and hosted on GitHub Pages.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
